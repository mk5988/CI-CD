# Material da aula guiada de CI CD

Abra ROTEIRO_ALUNO.md ou o roteiro Word disponibilizado pelo professor. Registre as respostas em RESPOSTAS.md.

- projeto_inicial contém apenas a aplicação e o package.json inicial. Na etapa 2 envie para o GitHub os arquivos de DENTRO desta pasta, preservando site/.
- etapa_05 contém o arquivo de testes e a versão do package.json com o comando test. Use somente na etapa 5.
- workflows contém os dois modelos da automação. Na etapa 6 crie .github/workflows/ci-cd.yml no GitHub e cole o modelo 01. Na etapa 9 substitua o conteúdo do mesmo ci-cd.yml pelo modelo 02.
- Não envie a pasta do material inteira ao repositório. Cada etapa informa os arquivos e seus destinos.
- Os campos de evidência devem conter dados reais da conta da equipe.

A interface do GitHub pode variar. Os nomes Code, Actions, Settings, Pages e Commit changes identificam a função dos controles usados no roteiro.
